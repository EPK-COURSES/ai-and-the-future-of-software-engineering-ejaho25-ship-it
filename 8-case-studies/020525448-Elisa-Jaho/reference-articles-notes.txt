Initial research notes about AI in software engineering companies.

Companies selected for research:
- Microsoft
- Google
- Shopify
- Duolingo

Main topics:
- AI coding assistants
- Workflow automation
- Productivity improvements
- Challenges and limitations

# Day 2 Notes

Microsoft uses GitHub Copilot to help developers generate code suggestions automatically.

Advantages:
- Faster coding
- Better productivity

Challenges:
- AI-generated bugs
- Need for human verification

# Day 3 Notes

Shopify uses AI tools to improve developer productivity and automate repetitive tasks.

Main observations:
- AI improves workflow efficiency
- Developers still review AI-generated outputs
- Human decision making remains important

# Day 4 notes

Duolingo uses AI to automate content generation and improve language learning systems.

Main observations:
- AI supports scalability
- Faster generation of educational content
- Human review remains important for quality control
